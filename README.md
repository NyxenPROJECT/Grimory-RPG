# 📖 Grimoire RPG

RPG tactique au tour par tour, avec de la magie, qui se joue directement dans le navigateur.

## ▶️ Jouer

👉 **https://nyxenproject.github.io/Grimory-RPG/**

Aucune installation : ça marche sur PC, Android et iPhone.

## ✨ Le jeu

- Combats tactiques sur grille, avec points d'action (PA) et de mouvement (PM)
- Plusieurs magies et sorts, chacun avec sa portée et son coût
- Mode co-op en ligne à deux avec un code de salle
- Un univers original, inspiré par les RPG tactiques et les mondes de magie

## 📱 Sur téléphone

- **iPhone** : ouvre le lien dans Safari, puis Partager → *Sur l'écran d'accueil*
- **Android** : ouvre le lien dans Chrome, puis menu ⋮ → *Ajouter à l'écran d'accueil*
